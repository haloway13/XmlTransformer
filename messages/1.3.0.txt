XmlTransformer Upgrade Notes
============================

XmlTransformer has been updated!

What's New:
-----------
- Dynamic JAR Discovery: XmlTransformer now automatically detects any installed
  Saxon-HE (12.x or 13.x) and xmlresolver (6.x) JARs.
- Modern Java 17 / 21 LTS Support: Expanded path resolution for Apple Silicon and
  Intel Macs, Ubuntu, and Windows.
- Hardened Setup Scripts: Added administrator checks, verified downloads, and
  curl/wget fallbacks across all platforms.
- Updated Libraries: Setup scripts now download Saxon-HE 12.10 and xmlresolver 6.0.23.


Existing Installations:
-----------------------
Your existing setup will continue to work without any manual changes.

If you would like to upgrade your Saxon and xmlresolver libraries:
1. Re-run the setup script for your platform (or download the new JARs from Maven Central):
   • Windows: Run setup_XmlTransformer_windows.bat as Administrator.
   • Linux:   Run ./setup_XmlTransformer_ubuntu.sh
   • macOS:   Run ./setup_XmlTransformer_macos.sh
2. (Optional) You can delete the older Saxon-HE-12.9.jar and xmlresolver-6.0.6*.jar
   files from your Saxon directory to free up disk space.


For complete details and documentation, visit:
https://github.com/haloway13/XmlTransformer#upgrading
